Make your own branching video

Fork the repo, host it free on GitHub Pages, and build interactive videos with the visual editor — no platform, no monthly fee, no build step.

  1. Fork the repository

    On GitHub, fork randallard/branching-video into your own account. That gives you the player, the editor, and these instructions, all yours to change.

  2. Turn on GitHub Pages

    In your fork: Settings → Pages → Deploy from a branch → main / / (root). Your site goes live at https://<you>.github.io/branching-video/ and redeploys on every push.

  3. Get your video on YouTube

    Upload your footage as Unlisted and copy its URL (or the 11-character video ID). One long video works great — the player slices it by timestamps. Separate uploads work too for deep-dive asides.

  4. Run it locally

    You need a server (YouTube's embed API won't run from file://):

    pnpm install
pnpm dev        # serves on http://localhost:8080

    Then open http://localhost:8080/editor.html.

  5. Build a show in the editor

    Click New… and paste your YouTube URL — it scaffolds the config and pulls in the title. Add nodes for each segment (set start/end seconds), wire choices between them, and watch the live validation panel. When it's clean, Save As… into the live/ folder.

    Two branching patterns are built in: optional asides (viewer chooses to dive in, then resumes) and default asides (everyone sees it, with a skip button). See the README for the full schema.

  6. Refresh the show list & validate

    Update the landing page's manifest, then sanity-check the graph:

    pnpm manifest                          # rebuild live/manifest.json
node tools/validate-config.js live/your-show.json

  7. Commit & push

    Push your live/ configs and the manifest. GitHub Pages rebuilds automatically:

    git add live/ && git commit -m "Add my show"
git push

    Your show is now live at player.html?config=live/your-show.json and listed on your home page.

Full schema, deep-linking, and hosting notes are in the README. Questions or ideas? Open an issue on the repo.
